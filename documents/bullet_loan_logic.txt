1. Get all relevant PrimeRate values:
    a. Future loan -> list with only the latest prime value.
    b. On going loan -> list with the latest prime value before the first change in the loan dates range + all changes inside the date range.
    c. Past loan -> list with the latest prime value before the first change in the loan dates range + all changes inside the date range.

2. Create payments:
    For every month in loan range:
        a. calculate amount of effective days for that month (e.g first/last payment might not be of a full month).
        b. get all prime changes for that payment's month:
            i. if no changes were made that month (empty change list) - calculate interest payment as [effective days in month(if full month always count as 30) * (effective prime rate / 12)] * loan amount.
            ii. if there were changes for prime that month:
                calculate all chunks (amount of days with each prime rate). Calculate as [(correlating prime rate * (affected days / effective days in the month / 12)) * loan amount] and sum all chunks.
